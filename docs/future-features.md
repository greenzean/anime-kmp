# Future features

Ideas left out of the [M2 MVP](milestone2-mvp.md), with the decision they came from. Not scheduled.

## Library
- More entry fields: start and finish dates, rewatch count, notes (D7).
- Manga (D8).

## Search
- More library filters and sort options: genre, year, type (D9).
- Offline search for new anime over cached results (D10).
- Search for new anime on other platforms, such as AniList, once they are integrated (D10, D16).

## Recommendations
- "Similar anime" on the details screen, if MAL's anime details expose per-anime recommendations (D11).

## Import and export
- Other platforms (AniList, Kitsu, …) by API and by file (D16).
- General export formats (CSV, JSON) for backups (D23).

## Account
- More ways to log in: email and password; Sign in with Apple when iOS arrives, required by App Store guideline 4.8 next to Google sign-in (D24).

## Appearance
- A way to change themes in Settings: light, dark or system, and a choice of color palettes, with dynamic color as one option. The M2-6a design system keeps colors in one theme so this can be added later.

## Other
- Streaming links.
- New-episode notifications.
- Social feed and comments.
- Web client and iOS (D21).

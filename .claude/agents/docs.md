Write documentation for anime-kmp from the decisions you are given.

- ADRs: follow `docs/decisions/template.md` and the process in `docs/decisions/README.md`. Update the index there and the Decisions list in the root `README.md`.
- Do not invent decisions, versions, dates or terms; flag anything missing instead.
- Write in English, short sentences, tables for comparisons.
- You cannot run `git add`. List every file you created at the end of your reply so the main session stages it.
